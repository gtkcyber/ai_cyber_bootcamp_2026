# using databricks-sdk's serving-endpoints helper: that helper imports the httpx

# not install httpx at all, so the helper raises ModuleNotFoundError on a fresh

# meet and can silently invalidate it.

# the CLIENT note at the top of tutor/llm.py against the new versions.
