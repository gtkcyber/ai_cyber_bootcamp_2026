## What the PDFs actually are (measured, 2026-09-02)

Every number below came from running PyMuPDF over the real files. The
classification heuristic in Task 4 is built on these measurements, not on an
assumption about how Keynote exports builds.

**The corpus.** 16 PDFs, 1,269 pages, every page exactly 1920×1080 points,
every page landscape. 1,268 of 1,269 pages carry extractable text (one page in
Module 0 does not). No PDF carries presenter notes or annotations. 15 of the 16
decks stamp the words "GTK Cyber" on more than 80% of their pages as a footer;
`Final Project.pdf` stamps nothing.

**Keynote did not export build stages as position-stable pages.** The obvious
test — the earlier page's text sitting at the same coordinates on the later
page — finds zero pairs at any useful threshold across the three probed decks.
Module 1 pages 10 and 11 are the same slide with one line added, and every
element on the page moves up 254 points between them, because the author
re-laid the slide out rather than adding a build stage. Nor is there a slide
number to group by: no deck carries a repeating slide-number placeholder.
What does survive is the **words**. On a genuine continuation every word of
the earlier page reappears on the later one, and the later one has more.

**Image identity has to come from content, not from the PDF object.** Keynote
re-embeds the same bitmap on each page, so `page.get_images()` xrefs differ
between two pages showing the same picture. `page.get_image_info(hashes=True)`
returns an MD5 of the pixels plus a placement rectangle, and that is stable.

**PyMuPDF cannot write WebP.** `Pixmap.tobytes` accepts only
`png, pnm, pgm, ppm, pbm, pam, tga, psd, ps`. Pillow does the encode.

**Rendering is cheap and deterministic.** At 1600×900, quality 82, `method=6`:
0.12–0.14 s per page, mean 35 KB per page, largest page measured 94 KB. The
whole course is about 2.8 minutes of CPU and roughly 45 MB of WebP — small
enough to commit. Encoding the same page twice gives byte-identical output.

## Assumptions (flagged for the coordinator)

1. **The deck `<title>` and the viewer's deck list disagree.** The brief
   specifies `<title>AI Cyber Bootcamp 2026 &mdash; Module N: Name</title>`.
   The reference viewer's `list_decks` builds its label as
   `f"Module {n} — {title after the em dash}"`, so that title renders in the
   deck list as "Module 3 — Module 3: Feature Engineering". This plan emits
   the title exactly as specified and flags the consequence: the bootcamp's
   copy of `deck-viewer/app.py` should strip a leading `Module N:` from
   `deck_name`, which is one line in the viewer's own plan. `Final Project`
   has no module number and will list as "Module 15 — Final Project".
2. **`unsure` never merges.** `emit_deck` treats an `unsure` page as ending
   its group, so an unreviewed deck is always over-split rather than
   over-merged. A wrongly split build shows the reader two static slides; a
   wrongly merged pair hides a slide behind a fragment click.
3. **`group` is derived, never trusted.** The brief asks for `{page, kind,
   group}` in the JSON, and the file is hand-editable. A human who flips a
   `kind` will not renumber the groups, so `load_pages` recomputes `group`
   from `kind` on every read and ignores whatever the file says.
4. **The overflow guard runs in the browser, not in the gate.** `deck.js`
   measures live DOM against the canvas, and this VM has no browser. The gate
   substitutes the arithmetic that would cause a clip: every page image is
   exactly 1600×900 and the canvas is 1600×900. The runtime guard is observed
   during the deployed-app spot check in the spec's Verification section.
5. **`upload_decks.py` drives `bin/databricks fs cp`, not the Databricks SDK.**
   The venv is specified as `pymupdf pillow pytest`, and the CLI already ships
   an 8-way concurrent copy (`--concurrency`, default 8). Using it keeps every
   Databricks call on the project-local CLI with `-p gtk-workspace`, which is
   a global constraint, and adds no dependency.

```python
#!/usr/bin/env python3
"""Build the AI Cyber Bootcamp reveal decks from the Keynote PDF exports.

    .venv/bin/python databricks/tools/build_decks.py --all
    .venv/bin/python databricks/tools/build_decks.py --deck 08-deep-learning

Each PDF page becomes a 1600x900 WebP. Consecutive pages that are stages of
one Keynote build collapse into a single reveal slide whose earlier stages are
fragments layered under the finished page, so advancing replays what the room
saw. The classification is written once to databricks/pages/<slug>.json and
never rewritten, because a human correction there has to survive a rebuild.
"""

from __future__ import annotations

import argparse
import html
import json
import re
import sys
from collections import Counter
from pathlib import Path

import pymupdf
from PIL import Image

REPO_ROOT = Path(__file__).resolve().parents[2]

MODULE_RE = re.compile(r"^Module\s+(\d{1,2})\s*[-–—:]?\s*(.+)$")
FINAL_PROJECT_NUMBER = 15


def _slugify(text: str) -> str:
    return re.sub(r"-+", "-", re.sub(r"[^a-z0-9]+", "-", text.lower())).strip("-")


def slug_for(pdf_name: str) -> str:
    """'Module 3 - Feature Engineering.pdf' -> '03-feature-engineering'.

    The Final Project is not a module and has no number of its own; it sorts
    last, so it takes 15.
    """
    stem = Path(pdf_name).stem.strip()
    if stem.lower() == "final project":
        return f"{FINAL_PROJECT_NUMBER:02d}-final-project"
    match = MODULE_RE.match(stem)
    if not match:
        raise ValueError(f"cannot derive a deck slug from {pdf_name!r}")
    return f"{int(match.group(1)):02d}-{_slugify(match.group(2))}"


def title_for(pdf_name: str) -> str:
    """The part of the deck's <title> after the em dash."""
    stem = Path(pdf_name).stem.strip()
    if stem.lower() == "final project":
        return "Final Project"
    match = MODULE_RE.match(stem)
    if not match:
        raise ValueError(f"cannot derive a deck title from {pdf_name!r}")
    return f"Module {int(match.group(1))}: {' '.join(match.group(2).split())}"
```

```python
# The reveal canvas and the page images are the same size on purpose: a slide
# that is exactly the canvas cannot trip deck.js's overflow guard.
PAGE_WIDTH = 1600
PAGE_HEIGHT = 900
WEBP_QUALITY = 82


def render_pages(pdf_path, out_dir, width=PAGE_WIDTH, height=PAGE_HEIGHT,
                 quality=WEBP_QUALITY):
    """Render every page of one PDF to <out_dir>/pNNN.webp. Returns the paths.

    PyMuPDF has no WebP writer of its own -- Pixmap.tobytes accepts png, pnm,
    pgm, ppm, pbm, pam, tga, psd and ps and nothing else -- so the pixmap goes
    through Pillow. method=6 is the encoder's slowest and best setting; at
    roughly 0.13 s a page over 1,269 pages that is under three minutes for the
    whole course, and it makes the output reproducible.
    """
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    written = []
    with pymupdf.open(pdf_path) as doc:
        for number, page in enumerate(doc, start=1):
            matrix = pymupdf.Matrix(width / page.rect.width,
                                    height / page.rect.height)
            pixmap = page.get_pixmap(matrix=matrix, alpha=False)
            image = Image.frombytes("RGB", (pixmap.width, pixmap.height),
                                    pixmap.samples)
            path = out_dir / f"p{number:03d}.webp"
            image.save(path, "WEBP", quality=quality, method=6)
            written.append(path)
    return written
```

```python
# ---------------------------------------------------------------- classify
#
# Keynote did not export build stages as position-stable pages. Measuring the
# real files: the earlier page's text sits at the same coordinates on the
# later page in zero pairs across three probed decks, because the author
# re-laid each stage out by hand -- Module 1 pages 10 and 11 are one slide
# with one line added and every element moves 254 points up between them. No
# deck carries a repeating slide-number placeholder either. What survives is
# the words: on a genuine continuation every word of the earlier page
# reappears on the later one, and the later one says more.
#
# Thresholds, each measured rather than picked:
#
#   BUILD_THRESHOLD 0.95  Genuine continuations in Module 1 score 0.95 to
#                         1.00. The one that scores 0.92 (page 132 into 133)
#                         is a stage the author reflowed, and it is the reason
#                         the band below exists rather than the reason to
#                         lower the bar.
#   UNSURE_THRESHOLD 0.70 Below this the pages share only stock vocabulary.
#   MIN_STAGE_TOKENS 3    A full-bleed section divider carries nothing but the
#                         deck footer, which chrome-stripping removes, leaving
#                         zero content words. Three keeps
#                         `series.value_counts()` -- a real one-line stage.
#   MAX_GROWTH 5.0        A page that grows more than fivefold is the title
#                         card pattern: a heading alone, then the heading over
#                         a full slide. Section break or build stage is not
#                         decidable from the PDF, so it goes to a human.
#   CHROME_SHARE 0.8      A word on four fifths of the pages is furniture.
#                         "GTK Cyber" is on every page of fifteen decks.
#   MIN_CHROME_PAGES 4    Below four pages, "four fifths of the pages" is
#                         "nearly all of them", so two pages that really are
#                         stages of one build would have their shared words
#                         stripped as furniture and look unrelated. The
#                         smallest real deck is seven pages, so this floor
#                         never fires on the course and only keeps small
#                         fixtures honest.
BUILD_THRESHOLD = 0.95
UNSURE_THRESHOLD = 0.70
MIN_STAGE_TOKENS = 3
MAX_GROWTH = 5.0
CHROME_SHARE = 0.8
MIN_CHROME_PAGES = 4

WORD_RE = re.compile(r"[a-z0-9]+")


def _page_facts(doc):
    """Words, image identities and raw text, one entry per page.

    Image identity comes from get_image_info(hashes=True), which gives an MD5
    of the pixels and a placement rectangle. It cannot come from get_images()
    xrefs: Keynote re-embeds the same bitmap on every page it appears on, so
    two pages showing one picture carry two different xrefs.
    """
    facts = []
    for page in doc:
        text = page.get_text("text")
        facts.append({
            "tokens": Counter(WORD_RE.findall(text.lower())),
            "images": Counter(
                (info["digest"], round(info["bbox"][0] / 2),
                 round(info["bbox"][1] / 2))
                for info in page.get_image_info(hashes=True)),
            "text": " ".join(text.split()),
        })
    return facts


def _strip_chrome(facts):
    """Drop words that appear on most pages: they are the deck's furniture.

    Fifteen of the sixteen decks stamp 'GTK Cyber' on every page. Counted as
    content it would make every sparse page look like a stage of the next one.
    The four-page floor stops the share test from swallowing everything two
    pages happen to share. Returns the words removed, for the record.
    """
    seen = Counter()
    for fact in facts:
        seen.update(set(fact["tokens"]))
    chrome = {word for word, pages in seen.items()
              if pages >= max(MIN_CHROME_PAGES, CHROME_SHARE * len(facts))}
    for fact in facts:
        for word in chrome:
            del fact["tokens"][word]
    return sorted(chrome)


def _containment(earlier, later):
    """Fraction of the earlier page's words that reappear on the later one."""
    if not earlier:
        return 1.0
    return sum((earlier & later).values()) / sum(earlier.values())


def _kind(earlier, later):
    """Is `earlier` a build stage that continues into `later`?"""
    n_earlier = sum(earlier["tokens"].values())
    n_later = sum(later["tokens"].values())
    if n_later <= n_earlier:
        return "slide"
    overlap = _containment(earlier["tokens"], later["tokens"])
    if overlap >= BUILD_THRESHOLD:
        if n_earlier < MIN_STAGE_TOKENS:
            return "slide"
        if len(later["images"]) < len(earlier["images"]):
            return "slide"
        return "build" if n_later <= MAX_GROWTH * n_earlier else "unsure"
    if overlap >= UNSURE_THRESHOLD:
        return "unsure"
    return "slide"


def group_ids(kinds):
    """One group id per page. A 'build' page joins the page after it.

    'unsure' ends its group: an unreviewed deck is over-split rather than
    over-merged, because a wrongly split build shows two static slides while a
    wrongly merged pair hides a slide behind a fragment click.
    """
    ids, current = [], 1
    for kind in kinds:
        ids.append(current)
        if kind != "build":
            current += 1
    return ids


def classify_pages(pdf_path):
    """One dict per page: {page, kind, group, text}, page numbers 1-based."""
    with pymupdf.open(pdf_path) as doc:
        facts = _page_facts(doc)
    _strip_chrome(facts)
    kinds = ["slide"] * len(facts)
    for index in range(len(facts) - 1):
        kinds[index] = _kind(facts[index], facts[index + 1])
    return [
        {"page": index + 1, "kind": kind, "group": gid, "text": facts[index]["text"]}
        for index, (kind, gid) in enumerate(zip(kinds, group_ids(kinds)))
    ]


def final_pages(pages):
    """The last page of each group: the page the reader ends up looking at."""
    last = {}
    for page in pages:
        last[page["group"]] = page["page"]
    return [last[gid] for gid in sorted(last)]


def pages_path(root, slug):
    return Path(root) / "databricks" / "pages" / f"{slug}.json"


def save_pages(root, slug, pdf_name, pages):
    """Write the classification if it is not already there. (path, written?).

    Never overwrites. The file is the human override surface: someone who
    flips a kind must not lose that edit to the next rebuild.
    """
    path = pages_path(root, slug)
    if path.exists():
        return path, False
    path.parent.mkdir(parents=True, exist_ok=True)
    payload = {"slug": slug, "pdf": pdf_name, "page_count": len(pages),
               "pages": pages}
    path.write_text(json.dumps(payload, indent=2, ensure_ascii=False) + "\n",
                    encoding="utf-8")
    return path, True


def load_pages(root, slug):
    """Read the classification, recomputing `group` from `kind`.

    A hand edit changes `kind` and leaves `group` stale, so the stored group
    is informational only and the derived one is what the build uses.
    """
    payload = json.loads(pages_path(root, slug).read_text(encoding="utf-8"))
    pages = payload["pages"]
    for page, gid in zip(pages, group_ids([p["kind"] for p in pages])):
        page["group"] = gid
    return payload
```

```python
# ------------------------------------------------------------------- notes
#
# One markdown file per deck, one '## Page N' section per final slide, N being
# the PDF page number of the slide the reader ends up looking at. UNRESOLVED
# as the whole body is the writer saying the talking points are not inferable
# from the slide -- which goes to Curtis rather than getting invented.
UNRESOLVED = "UNRESOLVED"

NOTE_HEADING_RE = re.compile(r"^##\s+Page\s+(\d+)\s*$", re.M)
CODE_SPAN_RE = re.compile(r"`([^`]+)`")


def notes_path(root, slug):
    return Path(root) / "databricks" / "notes" / f"{slug}.md"


def load_notes(root, slug):
    """{final page number: note body}. A missing file is an empty mapping."""
    path = notes_path(root, slug)
    if not path.exists():
        return {}
    text = path.read_text(encoding="utf-8")
    headings = list(NOTE_HEADING_RE.finditer(text))
    notes = {}
    for index, heading in enumerate(headings):
        end = headings[index + 1].start() if index + 1 < len(headings) else len(text)
        page = int(heading.group(1))
        if page in notes:
            raise ValueError(f"{path}: page {page} has two '## Page' headings")
        notes[page] = text[heading.end():end].strip()
    return notes


def _inline(text):
    return CODE_SPAN_RE.sub(lambda m: f"<code>{m.group(1)}</code>",
                            html.escape(text, quote=False))


def note_html(body):
    """Paragraphs, dash lists and inline code. Deliberately not a markdown
    engine: the notes register bans everything richer, and a dependency for
    two constructs is not worth carrying."""
    body = body.strip()
    if not body:
        return ""
    blocks = []
    for block in re.split(r"\n\s*\n", body):
        lines = [line.strip() for line in block.splitlines() if line.strip()]
        if not lines:
            continue
        if all(line.startswith("- ") for line in lines):
            items = "".join(f"<li>{_inline(line[2:])}</li>" for line in lines)
            blocks.append(f"<ul>{items}</ul>")
        else:
            blocks.append(f"<p>{_inline(' '.join(lines))}</p>")
    return "\n".join(blocks)
```

```python
# -------------------------------------------------------------------- emit
#
# The skeleton is the reference course's deck head and tail with the markdown
# textarea replaced by literal sections, because these slides are images and
# there is no markdown to parse. Reveal, its theme and its plugins stay pinned
# to 5.2.1 on the CDN, and the markdown plugin stays loaded because deck.js's
# default plugin list names it.
COURSE_NAME = "AI Cyber Bootcamp 2026"

SKELETON = """<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0, \
maximum-scale=1.0, user-scalable=no">
  <title>{title}</title>

  <!-- reveal.js, basic setup: CDN, pinned, no build step, runs from file:// -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/reveal.js@5.2.1/dist/reveal.css">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/reveal.js@5.2.1/dist/theme/white.css" id="theme">
  <!-- Shared across every deck in the course. Sixteen decks, one look. -->
  <link rel="stylesheet" href="../assets/reveal-a11y/helper.css">
  <link rel="stylesheet" href="../assets/course.css">
</head>
<body>
<div class="reveal">
<div class="slides">
{sections}
</div>
</div>

<script src="https://cdn.jsdelivr.net/npm/reveal.js@5.2.1/dist/reveal.js"></script>
<script src="https://cdn.jsdelivr.net/npm/reveal.js@5.2.1/plugin/markdown/markdown.js"></script>
<script src="https://cdn.jsdelivr.net/npm/reveal.js@5.2.1/plugin/highlight/highlight.js"></script>
<script src="https://cdn.jsdelivr.net/npm/reveal.js@5.2.1/plugin/notes/notes.js"></script>
<script src="../assets/deck.js"></script>
<script>
  CourseDeck.start();
</script>
</body>
</html>
"""

ALT_LIMIT = 180


def _alt_text(page):
    """The words on the page, for a reader who cannot see it.

    The note is the real explanation, but a screen reader in slide mode never
    reaches the note, so the slide's own text is the best alt available.
    """
    text = " ".join(page.get("text", "").split())[:ALT_LIMIT]
    return html.escape(text or f"Slide {page['page']}", quote=True)


def _section(stages, note):
    """One reveal slide: the group's pages stacked, then the note.

    The group's first page is the base layer and each later stage is a
    fragment above it, so one keypress per stage replays the build and the
    finished page ends up on top. Reading mode strips the fragment class but
    not the stacking order, so it shows the finished page.
    """
    layers = []
    for index, page in enumerate(stages):
        css_class = "page" if index == 0 else "page fragment"
        layers.append(f'      <img class="{css_class}" '
                      f'src="pages/p{page["page"]:03d}.webp" '
                      f'alt="{_alt_text(page)}">')
    body = "\n".join(layers)
    rendered = (f'<p class="unresolved">{UNRESOLVED}</p>'
                if note.strip() == UNRESOLVED else note_html(note))
    aside = (f'    <aside class="notes">\n      {rendered}\n    </aside>\n'
             if rendered else "")
    return (f"  <section>\n"
            f'    <div class="page-stack">\n{body}\n    </div>\n'
            f"{aside}"
            f"  </section>")


def emit_deck(root, slug, title, pages, notes):
    """Write decks/<slug>/index.html. Returns the path."""
    by_group = {}
    for page in pages:
        by_group.setdefault(page["group"], []).append(page)

    sections = []
    for gid in sorted(by_group):
        stages = sorted(by_group[gid], key=lambda p: p["page"])
        sections.append(_section(stages, notes.get(stages[-1]["page"], "")))

    path = Path(root) / "decks" / slug / "index.html"
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(
        SKELETON.format(title=f"{COURSE_NAME} &mdash; {title}",
                        sections="\n".join(sections)),
        encoding="utf-8")
    return path
```

```python
# --------------------------------------------------------------------- cli


def pdf_for(root, slug):
    """The Keynote export behind a slug."""
    for path in sorted((Path(root) / "slides").glob("*.pdf")):
        if slug_for(path.name) == slug:
            return path
    raise ValueError(f"no PDF in slides/ maps to slug {slug!r}")


def build_deck(root, pdf_path):
    """Render, classify, emit. Returns the counts Task 13 records."""
    root = Path(root)
    slug = slug_for(pdf_path.name)
    title = title_for(pdf_path.name)

    written = render_pages(pdf_path, root / "decks" / slug / "pages")
    _, created = save_pages(root, slug, pdf_path.name, classify_pages(pdf_path))
    payload = load_pages(root, slug)
    pages = payload["pages"]
    notes = load_notes(root, slug)
    index = emit_deck(root, slug, title, pages, notes)

    kinds = [page["kind"] for page in pages]
    finals = final_pages(pages)
    unresolved = sum(1 for page in finals
                     if notes.get(page, "").strip() == UNRESOLVED)
    return {
        "slug": slug,
        "title": title,
        "pdf_pages": len(pages),
        "final_slides": len(finals),
        "fragments": len(pages) - len(finals),
        "unsure": kinds.count("unsure"),
        "notes_written": sum(1 for page in finals if page in notes),
        "unresolved": unresolved,
        "classification_created": created,
        "pages_written": len(written),
        "index": index,
    }


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--root", default=str(REPO_ROOT),
                        help="course repo root (default: this file's repo)")
    group = parser.add_mutually_exclusive_group(required=True)
    group.add_argument("--deck", help="one deck slug, e.g. 08-deep-learning")
    group.add_argument("--all", action="store_true", help="every deck")
    args = parser.parse_args(argv)

    root = Path(args.root)
    if args.deck:
        pdfs = [pdf_for(root, args.deck)]
    else:
        pdfs = sorted((root / "slides").glob("*.pdf"))

    print(f"{'deck':<52} {'pages':>5} {'slides':>6} {'frags':>5} "
          f"{'unsure':>6} {'notes':>5}")
    for pdf_path in pdfs:
        result = build_deck(root, pdf_path)
        print(f"{result['slug']:<52} {result['pdf_pages']:>5} "
              f"{result['final_slides']:>6} {result['fragments']:>5} "
              f"{result['unsure']:>6} {result['notes_written']:>5}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
#!/usr/bin/env python3
"""Gate for the bootcamp decks. Run it before a deck is shown to anybody.

    .venv/bin/python databricks/tools/check_decks.py                 # every deck
    .venv/bin/python databricks/tools/check_decks.py --deck 08-deep-learning
    .venv/bin/python databricks/tools/check_decks.py --ship          # no UNRESOLVED
    .venv/bin/python databricks/tools/check_decks.py --unresolved    # the report

Exit status is the number of hard failures, capped at 125.

What it does not check: reveal's overflow guard, which measures live DOM in a
browser and has no browser here. Its arithmetic is covered instead -- every
page image is exactly the canvas size, so an image slide cannot clip. The
runtime guard is watched during the deployed-app spot check.
"""

from __future__ import annotations

import argparse
import re
import sys
from pathlib import Path

from PIL import Image

sys.path.insert(0, str(Path(__file__).resolve().parent))

from build_decks import (PAGE_HEIGHT, PAGE_WIDTH, REPO_ROOT, UNRESOLVED,
                         COURSE_NAME, final_pages, load_notes, load_pages,
                         pages_path)
from checks import prose

IMG_RE = re.compile(r'<img class="page(?: fragment)?" src="([^"]+)"')
SECTION_RE = re.compile(r"<section>")
TITLE_RE = re.compile(r"<title>(.*?)</title>", re.S)
EXIT_CAP = 125


def deck_slugs(root):
    meta = Path(root) / "databricks" / "pages"
    return sorted(path.stem for path in meta.glob("*.json"))


def check_deck(root, slug, ship=False):
    """(failures, warnings) for one deck. Both are lists of prefixed strings."""
    root = Path(root)
    failures, warnings = [], []
    where = f"{slug}:"

    if not pages_path(root, slug).exists():
        return [f"{where} databricks/pages/{slug}.json is missing"], []
    payload = load_pages(root, slug)
    pages = payload["pages"]
    finals = final_pages(pages)

    unsure = [page["page"] for page in pages if page["kind"] == "unsure"]
    if unsure:
        warnings.append(f"{where} {len(unsure)} unsure page(s) never reviewed: "
                        f"{', '.join(str(n) for n in unsure)}")

    index_path = root / "decks" / slug / "index.html"
    if not index_path.is_file():
        return failures + [f"{where} decks/{slug}/index.html is missing"], warnings
    markup = index_path.read_text(encoding="utf-8")

    title = TITLE_RE.search(markup)
    if not title or not title.group(1).startswith(f"{COURSE_NAME} &mdash; "):
        got = title.group(1) if title else "(none)"
        failures.append(f"{where} title is {got!r}, expected "
                        f"'{COURSE_NAME} &mdash; <name>'")

    sections = len(SECTION_RE.findall(markup))
    if sections != len(finals):
        failures.append(f"{where} {sections} <section> in the deck, "
                        f"{len(finals)} final slide(s) in the classification")

    sources = IMG_RE.findall(markup)
    if len(sources) != len(pages):
        failures.append(f"{where} {len(sources)} page image(s) in the deck, "
                        f"{len(pages)} page(s) in the PDF")

    for source in sources:
        image_path = index_path.parent / source
        if not image_path.is_file():
            failures.append(f"{where} {source} is referenced and missing")
            continue
        with Image.open(image_path) as image:
            if image.size != (PAGE_WIDTH, PAGE_HEIGHT):
                failures.append(
                    f"{where} {source} is {image.size[0]}x{image.size[1]}, "
                    f"expected {PAGE_WIDTH}x{PAGE_HEIGHT}")

    try:
        notes = load_notes(root, slug)
    except ValueError as bad_file:
        # One malformed notes file must not stop the other fifteen decks
        # from being checked.
        return failures + [f"{where} {bad_file}"], warnings
    for page in finals:
        body = notes.get(page, "").strip()
        if not body:
            failures.append(f"{where} page {page} has no note and no "
                            f"{UNRESOLVED} marker")
            continue
        if body == UNRESOLVED:
            message = f"{where} page {page} is still {UNRESOLVED}"
            (failures if ship else warnings).append(message)
            continue
        for finding in prose.check_note(body):
            failures.append(f"{where} page {page}: {finding}")

    orphans = sorted(set(notes) - set(finals))
    if orphans:
        failures.append(f"{where} note(s) for non-final page(s): "
                        f"{', '.join(str(n) for n in orphans)}")
    return failures, warnings


def unresolved_rows(root, slugs):
    """(slug, page, the words on that slide) for every unresolved note."""
    rows = []
    for slug in slugs:
        payload = load_pages(root, slug)
        text = {page["page"]: page["text"] for page in payload["pages"]}
        notes = load_notes(root, slug)
        for page in final_pages(payload["pages"]):
            if notes.get(page, "").strip() == UNRESOLVED:
                rows.append((slug, page, text.get(page, "")))
    return rows


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--root", default=str(REPO_ROOT))
    parser.add_argument("--deck", help="one deck slug (default: all of them)")
    parser.add_argument("--ship", action="store_true",
                        help=f"treat {UNRESOLVED} as a failure")
    parser.add_argument("--unresolved", action="store_true",
                        help="print the unresolved report and stop")
    args = parser.parse_args(argv)

    root = Path(args.root)
    slugs = [args.deck] if args.deck else deck_slugs(root)

    if args.unresolved:
        rows = unresolved_rows(root, slugs)
        for slug, page, text in rows:
            print(f"{slug}\tp{page:03d}\t{text[:160]}")
        print(f"\n{len(rows)} unresolved slide(s) across {len(slugs)} deck(s)",
              file=sys.stderr)
        return 0

    failures, warnings = [], []
    for slug in slugs:
        deck_failures, deck_warnings = check_deck(root, slug, ship=args.ship)
        failures += deck_failures
        warnings += deck_warnings

    for warning in warnings:
        print(f"  WARN  {warning}")
    for failure in failures:
        print(f"  FAIL  {failure}")
    print(f"\n{len(slugs)} deck(s): {len(failures)} failure(s), "
          f"{len(warnings)} warning(s)")
    return min(len(failures), EXIT_CAP)


if __name__ == "__main__":
    sys.exit(main())
```

````
2026, ported from a Keynote export to reveal.js. You are the only writer for
this deck, so every phrase you use is a phrase you have to remember not to
reuse later in the same deck.

SLIDES: [N] final slides, page numbers listed in the JSON below.

WORKING DIRECTORY: /home/curtis/claude_projects/gtk_aws/ai_cyber_bootcamp_2026

YOUR INPUTS
- databricks/pages/[SLUG].json — one entry per PDF page: `page` (number),
  `kind` ("slide", "build" or "unsure"), `group`, and `text`, the words
  PyMuPDF extracted from that page. Pages sharing a `group` are stages of one
  slide; the LAST page of each group is the final slide and the only one that
  gets a note.
- decks/[SLUG]/pages/pNNN.webp — the rendered page images, one per page,
  1600x900. Read them. Many slides are screenshots, diagrams or charts whose
  content is not in the extracted text at all.

YOUR OUTPUT
- databricks/notes/[SLUG].md — one section per final slide:

      ## Page 12

      The note body.

  Sections in ascending page order. Every final slide gets exactly one
  section. Use `## Page N` with N the final page number of the group, never
  the slide's position in the deck.

HOW TO WORK
Work in batches of 25 final slides. For each batch: read that batch's page
images, write those sections, append them to the notes file, then move on.
Keep a running list of the distinctive phrases you have spent so far and check
each new note against it before you write. Do not read the whole deck's images
at once.

WHAT A NOTE IS
Student-facing prose with two readers: a presenter glancing down, and — most
of the time — a student reading the deck alone months later with no presenter
and no animation running. The slide points, the note explains. The bar is that
a student reading cold can follow the thread. Two to four paragraphs for a
content slide; one for a simple one. A section-divider slide gets one or two
sentences saying what the part covers.

THE REGISTER
Textbook, minus the padding: facts and explanations in the fewest words that
keep them.
- Claim first. A paragraph opens with one flat sentence stating its point,
  then the facts that support it.
- Delete beats rewrite. A sentence whose job is decoration, preview or
  restatement gets cut, not restyled.
- Lists run category first, then name-colon-gloss per item.
- A failure mode is its concrete effect, with the mechanism, not a named
  hazard on its own.
- Scope every claim to exactly what is true.
- Arithmetic is spelled in words, not named as an operation.
- Short imperatives are fine. Second person only for what the reader does.
- A term of art is welcome with a clause-length gloss on first use. Coined
  terms are banned. A proper-noun term gets one full introduction on first use
  in the deck: whose name it is, what the named thing does here, and the
  pronunciation when the spelling misleads.
- US spelling. No dashes in prose; semicolons sparingly.

BANNED DEVICES — each named because general instructions miss them
1. Doubling: anaphora, mirrored pairs, not-X-but-Y in any form, and the same
   fact restated within or across paragraphs.
2. Non-fact openers: wind-ups, scene-setting, previews of what the next
   paragraph says anyway, throat-clearing.
3. Dramatization: stakes narration, escalating triads, cinematic color, drama
   adverbs ("silently"), emphatics ("never", "completely").
4. Metaphor in place of mechanism.
5. Imagined people and scenes: the colleague you explain to, "on an
   incident", enumerated scenarios standing in for a general fact.
6. Inflation and litotes: "not cheap", "costs real compute", "worth reasoning
   about".
7. Coy teases: unnamed hazards, unnamed measures, "covered later". Name the
   thing or drop the reference.
8. Cutesy paraphrase over real terms.
9. Invented qualifiers: any unsourced prevalence, frequency or popularity
   claim ("most analysts", "rarely worth tuning", "usually"). If no source
   backs the quantifier, the sentence loses the quantifier, not the fact.
10. Presentation mechanics: clicks, animations, reveals, "the slide shows".
    The note is read textbook style by someone with no presenter running.
11. The nameable hedge: "a cluster you can name". Name the actual thing.

NO PRESENTER CUES. Not as a cue block, and not smuggled into the note as a
sentence. A presenter instruction is a guess about how somebody else will run
a room. Write the teaching only.

WHAT YOU MUST NOT DO
Do not invent teaching content. You are writing from a rendered slide with no
speaker notes behind it. When a slide's talking points cannot be inferred from
what is on it — a bare screenshot with no caption, a chart with no axis
labels, a photograph, a slide whose only text is a URL, a code listing whose
purpose is not stated anywhere in the deck — write exactly this as the whole
body:

      UNRESOLVED

One word, alone, no punctuation and no explanation. Curtis will supply the
talking points, or the Keynote source will. A wrong note costs more than a
missing one, and the UNRESOLVED list is a deliverable, not a failure.

Use the surrounding slides for context before you give up: a screenshot two
slides after a labelled diagram is usually inferable. Guessing what a chart
means because a chart is usually about something is not.
````

```python
#!/usr/bin/env python3
"""Push decks/ to the app volume.

    .venv/bin/python databricks/tools/upload_decks.py --dry-run
    .venv/bin/python databricks/tools/upload_decks.py
    .venv/bin/python databricks/tools/upload_decks.py --deck 08-deep-learning

Idempotent by size: a file already on the volume at the same byte count is not
sent again. That is enough because the renderer is deterministic, so a file
whose bytes changed changed for a reason and almost always changed size too;
a deck rebuilt from an edited classification changes its section count and its
index.html size.

Concurrency comes from the Databricks CLI itself, which copies with eight
parallel operations by default. Reimplementing a thread pool around one
subprocess per file would be slower and would not be the project's CLI.
"""

from __future__ import annotations

import argparse
import json
import os
import subprocess
import sys
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parents[2]
GTK_AWS = Path(os.environ.get("GTK_AWS_HOME", "/home/curtis/claude_projects/gtk_aws"))
DATABRICKS = GTK_AWS / "bin" / "databricks"
PROFILE = "gtk-workspace"
VOLUME_ROOT = "dbfs:/Volumes/ai_cyber_bootcamp/course/app/decks"


def cli(args):
    """Run the project-local Databricks CLI. Returns (returncode, stdout)."""
    completed = subprocess.run(
        [str(DATABRICKS), *args, "-p", PROFILE],
        cwd=str(GTK_AWS), capture_output=True, text=True, check=False)
    if completed.returncode != 0:
        print(completed.stderr.strip(), file=sys.stderr)
    return completed.returncode, completed.stdout


def local_manifest(decks_dir):
    """{path relative to the volume root: size in bytes}."""
    decks_dir = Path(decks_dir)
    return {str(path.relative_to(decks_dir)): path.stat().st_size
            for path in sorted(decks_dir.rglob("*")) if path.is_file()}


def remote_manifest(run, volume_root=VOLUME_ROOT):
    """Same shape, read off the volume. `fs ls` does not recurse, so walk it."""
    found, queue = {}, [volume_root]
    while queue:
        directory = queue.pop()
        code, out = run(["fs", "ls", "--output", "json", "--absolute", directory])
        if code != 0:
            continue  # a directory that is not there yet is simply empty
        for entry in json.loads(out or "[]"):
            # Field names verified against Databricks CLI v1.14.1: an entry is
            # {name, is_directory, size, last_modified}, and --absolute makes
            # `name` the full dbfs: path rather than the basename.
            if entry["is_directory"]:
                queue.append(entry["name"])
            else:
                relative = entry["name"][len(volume_root) + 1:]
                found[relative] = int(entry["size"])
    return found


def stale(local, remote):
    """Paths present locally that the volume does not have at the same size."""
    return [path for path, size in sorted(local.items())
            if remote.get(path) != size]


def plan_uploads(decks_dir, stale_paths):
    """Group stale paths into the fewest CLI calls.

    A top-level directory that is entirely stale goes in one recursive copy;
    otherwise its stale files go one at a time. Returns (path, recursive?).
    """
    decks_dir = Path(decks_dir)
    by_top = {}
    for path in stale_paths:
        by_top.setdefault(path.split("/", 1)[0], []).append(path)

    plan = []
    for top in sorted(by_top):
        everything = {str(p.relative_to(decks_dir))
                      for p in (decks_dir / top).rglob("*") if p.is_file()}
        if everything and everything == set(by_top[top]):
            plan.append((top, True))
        else:
            plan += [(path, False) for path in sorted(by_top[top])]
    return plan


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--root", default=str(REPO_ROOT))
    parser.add_argument("--deck", help="one deck slug (default: everything)")
    parser.add_argument("--dry-run", action="store_true")
    args = parser.parse_args(argv)

    decks_dir = Path(args.root) / "decks"
    local = local_manifest(decks_dir)
    if args.deck:
        local = {p: s for p, s in local.items()
                 if p.startswith(f"{args.deck}/") or p.startswith("assets/")}

    remote = remote_manifest(cli)
    pending = stale(local, remote)
    plan = plan_uploads(decks_dir, pending)
    print(f"{len(local)} local file(s), {len(remote)} on the volume, "
          f"{len(pending)} to send in {len(plan)} call(s)")
    if args.dry_run:
        for path, recursive in plan:
            print(f"  {'dir ' if recursive else 'file'}  {path}")
        return 0

    failures = 0
    for path, recursive in plan:
        command = ["fs", "cp", "--overwrite"]
        if recursive:
            command.append("--recursive")
        command += [str(decks_dir / path), f"{VOLUME_ROOT}/{path}"]
        code, _ = cli(command)
        if code != 0:
            failures += 1
            print(f"  FAIL  {path}", file=sys.stderr)

    after = remote_manifest(cli)
    missing = stale(local, after)
    print(f"volume now holds {len(after)} file(s); "
          f"{len(missing)} still missing or wrong size")
    return failures + len(missing)


if __name__ == "__main__":
    sys.exit(main())
```
