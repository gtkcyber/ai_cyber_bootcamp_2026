# Bootcamp app and tutor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `bootcamp-slides`, a Databricks App that serves the 16 rendered reveal decks from a Unity Catalog volume with a built-in skills-based tutor, plus the bundle that deploys it and the two paused class-hours jobs.

**Architecture:** The app is a copy of `jupyter/courses/graph-analytics-cyber/databricks/deck-viewer` with the retrieval layer removed. Where the reference embedded a corpus offline and searched it with numpy, this tutor is a small function-calling agent: an index of skill names and descriptions rides in the system prompt, and four tools (`load_skill`, `read_reference`, `read_lab`, `read_deck_notes`) pull bodies on demand from the workspace files path and the decks volume. The knowledge itself is a generated, tutor-flavored derivative of `claude-skills/skills/data-science` plus one hand-written skill per course module. Everything deploys through one bundle at the course repo root.

**Tech Stack:** Databricks Asset Bundles (`bin/databricks bundle`, CLI v1.14), Databricks Apps (Python/gunicorn), Flask 3, `databricks-sdk`, `openai` 3.x against the workspace OpenAI-compatible serving endpoint, `databricks-deepseek-v4-flash-0731`, pytest. No numpy, no embeddings, no vector endpoint.

**Docs this is built from** (fetched 2026-09-02, quoted in the comments below):
- `resources.apps.<key>.permissions` is a sequence of mappings with `group_name` / `user_name` / `service_principal_name` plus a required `level`; for apps the valid levels are `CAN_MANAGE` and `CAN_USE` — https://docs.databricks.com/aws/en/dev-tools/bundles/reference#permissions and https://docs.databricks.com/aws/en/dev-tools/bundles/permissions ("Apps: `CAN_MANAGE`, `CAN_USE`").
- `resources.apps.<key>.resources` is a sequence; each entry is `name` plus exactly one resource map. `serving_endpoint` takes `name` and `permission`, "Valid values include `CAN_QUERY`, `CAN_MANAGE`, `CAN_VIEW`". `uc_securable` takes `securable_type` ("Valid values are `VOLUME`, `TABLE`, `FUNCTION`, and `CONNECTION`"), `securable_full_name` ("catalog.schema.name" format) and `permission` ("`VOLUME`: `READ_VOLUME`, `WRITE_VOLUME`") — https://docs.databricks.com/aws/en/dev-tools/bundles/resources#apps. `permission` is typed String, singular: **two permissions on one volume need two entries.**

Two facts from the reference that shape this code. First, `w.clusters.delete()` maps to the REST `clusters/delete` call, which **terminates** a cluster and leaves it restartable — it is not `permanent_delete()`. Second, on serverless `spark_python_task` the entry script has **no `__file__`**, so nothing here may compute a path from its own location, add to `sys.path`, or import a sibling module; both files are standalone and import only `sys` and the SDK.

```python
Two sources, one output tree:

  1. claude-skills/skills/data-science (READ-ONLY, a sibling project) — the

     ledger field names, the dispatch table, loop-back edges, re-entrancy
     flags, tier floors, and every line telling an agent to invoke another
     skill. What survives is the data-science knowledge itself: subfield
     triggers and canonical methods, selection trees, family pitfalls, domain

  2. The MODULES table in this file — one course-module-NN skill per bootcamp
     module, written by hand from the repo's notebooks and slide titles.

The derivative is generated, never hand-edited: editing tutor-skills/ directly
puts it out of step with the source suite, and the next run silently reverts
the edit. Change this script, or change the source, and re-run.

import json

import shutil
import sys
from pathlib import Path

# References that are data-science knowledge, kept. The other five
# (concept-ownership, dispatch-table, ledger-spec, loop-backs, tiers) are

    "doctrine-scale-cost",
    "encoding-chooser",
    "imputation-tree",

)


class LeakageError(Exception):
    """A cleaned description still contains agent-orchestration vocabulary.

    Raised rather than shipped: a tutor whose skill index tells a student to
    "invoke the router" is worse than a build that fails loudly.
    """


# --- description cleaning ------------------------------------------------

# The 37 subskills open with this byte-identical sentence.
_INTERNAL_PREFIX = "Internal — invoked via the data-science router."

# Sentences that exist only to steer an agent. Matched against whole sentences
# after whitespace normalisation, so a rule can never eat half a thought.
_DROP_SENTENCE_RES = (
    re.compile(r"^Do not invoke\b", re.I),
    re.compile(r"^Not re-entrant\b", re.I),
    re.compile(r"^Reference implementation for the [\w-]+ layer\.?$", re.I),
    re.compile(r"\brun-record\b", re.I),
    re.compile(r"\babort(s|ed)? back\b", re.I),
    re.compile(r"\bloop-backs?\b", re.I),
    re.compile(r"\bdispatch\b", re.I),
)

# Nothing matching this may survive into a description.
BANNED_WORDS_RE = re.compile(
    r"\b(invoke[sd]?|invoking|abort(s|ed|ing)?|run-record|ledger|dispatch(es|ed)?|"
    r"re-entrant|re_entrant|router|misroute|loop-back)\b",
    re.I,
)


def _sentences(text: str) -> list[str]:
    """Split on sentence-final punctuation followed by a space and a capital."""
    return [s.strip() for s in re.split(r"(?<=[.!?])\s+(?=[A-Z(`])", text) if s.strip()]


def clean_description(text: str) -> str:
    text = " ".join(text.split())
    if text.startswith(_INTERNAL_PREFIX):
        text = text[len(_INTERNAL_PREFIX):].lstrip()
    kept = [s for s in _sentences(text)
            if not any(rx.search(s) for rx in _DROP_SENTENCE_RES)]
    out = " ".join(kept).strip()
    # A sentence can carry a trailing clause that a whole-sentence rule misses;
    # trim the two shapes that actually occur, then refuse anything left over.
    out = re.sub(r"\s*\(serving wrapper:\s*`[^`]+`\)", "", out)
    out = re.sub(r";\s*sources the [^.]*\.", ".", out)
    out = " ".join(out.split())
    if BANNED_WORDS_RE.search(out):
        raise LeakageError(f"description still carries orchestration vocabulary: {out!r}")
    if len(out) > DESCRIPTION_MAX_CHARS:
        cut = out[:DESCRIPTION_MAX_CHARS].rsplit(" ", 1)[0]
        out = cut.rstrip(",;:") + "…"
    return out


# --- body stripping ------------------------------------------------------

# Whole sections that are pure machinery. `Artifact` is literally the ledger
# schema pointer; `Pairings` is the cross-skill composition list. The router's
# sections 2-4 are tier selection, dispatch and reference load order — its
# section 1 (the three classification axes) is a genuine taxonomy and stays.
DROP_HEADINGS_SUBSKILL = ("## Artifact", "## Pairings")
DROP_HEADINGS_ROUTER = ("## 2. Select tier", "## 3. Dispatch", "## 4. Reference load order")

# The two precondition forms, matched on whitespace-normalised text so the
# varying line-wrap inside Form A does not matter.
_PRECONDITION_RES = (
    re.compile(
        r"^>\s*Abort to the router .*?instruct the caller to invoke `data-science` first\.\s*$",
        re.I | re.S),
    re.compile(
        r"^\*\*Precondition\*\*:.*?do not run standalone\.\s*$",
        re.I | re.S),
)

# Lines that carry orchestration inside an otherwise-keepable section. Every
# pattern here was read off a real line in the source, not guessed.
DROP_LINE_RES = tuple(re.compile(p, re.I) for p in (
    r"^\s*Dispatch fields\b",
    r"\bdispatch-table(\.md)?\b",
    r"\bLedger section\b",
    r"\bledger-spec\.md\b",
    r"\bloop-backs\.md\b",
    r"\bconcept-ownership\.md\b",
    r"\bBACKLOG\.md\b",
    r"\blint_dangling\w*\b",
    r"\brun-record\b",
    r"\bthe router\b",
    r"\bmisroute\b",
    r"\bRe-run scope:",
    r"\bre_entrant\s*:",
    r"\bcomposed-alongside\s*:",
    r"\bload order\s*:\s*\d+",
    r"→\s*artifact:",
    r"^\s*Reciprocal \(`ds-[\w-]+` names `ds-[\w-]+` back\)\.\s*$",
    r"\bgate-executor rule\b",
    r"\bowner:\s*ds-[\w-]+",
    r"^\s*Invoke\b",
    r"\btier floor\b",
    r"^\s*participation\s*:",
    r"\bSKILL\.md §\d",
))


def _drop_precondition(body: str) -> str:
    """Remove the precondition block, which is always the first content after the H1."""
    lines = body.splitlines()
    out, i = [], 0
    # keep the H1 and the blank line under it
    while i < len(lines) and not lines[i].startswith("# "):
        out.append(lines[i])
        i += 1
    if i < len(lines):
        out.append(lines[i])
        i += 1
    while i < len(lines) and not lines[i].strip():
        i += 1
    # gather the candidate block: consecutive non-blank lines
    block_start = i
    while i < len(lines) and lines[i].strip():
        i += 1
    block = " ".join(" ".join(lines[block_start:i]).split())
    block = re.sub(r"^>\s*", "", block)
    block = re.sub(r"\s*>\s*", " ", block)
    if any(rx.match(block) for rx in _PRECONDITION_RES) or (
        "abort to the router" in block.lower() or "**precondition**" in block.lower()
    ):
        out.append("")
        out.extend(lines[i:])
    else:
        out.append("")
        out.extend(lines[block_start:])
    return "\n".join(out)


def _drop_sections(body: str, headings: tuple[str, ...]) -> str:
    """Drop each named `##` section up to the next `##` heading."""
    out, skipping = [], False
    for line in body.splitlines():
        if line.startswith("## "):
            skipping = any(line.strip() == h for h in headings)
        if not skipping:
            out.append(line)
    return "\n".join(out)


def _drop_lines(body: str) -> str:
    return "\n".join(ln for ln in body.splitlines()
                     if not any(rx.search(ln) for rx in DROP_LINE_RES))


def _drop_empty_sections(body: str) -> str:
    """Remove a heading whose whole body was stripped away."""
    lines = body.splitlines()
    out, i = [], 0
    while i < len(lines):
        line = lines[i]
        if line.startswith("#"):
            j = i + 1
            while j < len(lines) and not lines[j].strip():
                j += 1
            if j >= len(lines) or lines[j].startswith("#"):
                # the next thing is another heading or the end: this one is empty
                if not (line.startswith("# ") and not line.startswith("## ")):
                    i = j
                    continue
        out.append(line)
        i += 1
    return "\n".join(out)


def _tidy(body: str) -> str:
    body = re.sub(r"[ \t]+$", "", body, flags=re.M)
    body = re.sub(r"\n{3,}", "\n\n", body)
    return body.strip() + "\n"


def strip_body(body: str, *, is_router: bool) -> str:
    headings = DROP_HEADINGS_ROUTER if is_router else DROP_HEADINGS_SUBSKILL
    body = _drop_precondition(body)
    body = _drop_sections(body, headings)
    body = _drop_lines(body)
    body = _drop_empty_sections(body)
    return _tidy(body)


# --- frontmatter I/O -----------------------------------------------------

def split_frontmatter(text: str) -> tuple[dict, str]:
    """Parse the `name`/`description` frontmatter without a YAML dependency.

    The suite uses exactly two keys and folded (`>-`) descriptions; a hand
    parser keeps the app's requirements.txt free of PyYAML, which the app
    would otherwise carry only for this.
    """
    if not text.startswith("---"):
        raise ValueError("no frontmatter")
    _, fm, body = text.split("---", 2)
    meta, key = {}, None
    for raw in fm.splitlines():
        if not raw.strip():
            continue
        m = re.match(r"^(\w[\w-]*):\s*(.*)$", raw)
        if m and not raw.startswith((" ", "\t")):
            key, value = m.group(1), m.group(2).strip()
            meta[key] = "" if value in (">-", ">", "|", "|-") else value
        elif key is not None:
            meta[key] = (meta[key] + " " + raw.strip()).strip()
    return meta, body.lstrip("\n")


def render_skill(name: str, description: str, body: str) -> str:
    """Emit frontmatter with a single-line, double-quoted description.

    Quoting sidesteps every YAML special case a description can contain — a
    leading `#`, a `: ` pair, a leading `>` — with one escape rule.
    """
    escaped = description.replace("\\", "\\\\").replace('"', '\\"')
    return f'---\nname: {name}\ndescription: "{escaped}"\n---\n\n{body.strip()}\n'


# --- the data-science half ----------------------------------------------

def build_data_science(src: Path, dest: Path) -> list[dict]:
    """Write the stripped router, subskills and kept references. Returns index entries."""
    entries: list[dict] = []

    def emit_skill(name: str, text: str, *, is_router: bool) -> None:
        meta, body = split_frontmatter(text)
        description = clean_description(meta["description"])
        out_body = strip_body(body, is_router=is_router)
        rel = f"{name}/SKILL.md"
        path = dest / rel
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(render_skill(name, description, out_body), encoding="utf-8")
        entries.append({"kind": "skill", "name": name, "description": description, "path": rel})

    emit_skill("data-science", (src / "SKILL.md").read_text(encoding="utf-8"), is_router=True)

    for skill_dir in sorted((src / "subskills").iterdir()):
        skill_md = skill_dir / "SKILL.md"
        if skill_md.is_file():
            emit_skill(skill_dir.name, skill_md.read_text(encoding="utf-8"), is_router=False)

    ref_dir = dest / "references"
    ref_dir.mkdir(parents=True, exist_ok=True)
    for name in KEEP_REFERENCES:
        text = (src / "references" / f"{name}.md").read_text(encoding="utf-8")
        text = _tidy(_drop_lines(text))
        (ref_dir / f"{name}.md").write_text(text, encoding="utf-8")
        first = next((ln.strip() for ln in text.splitlines() if ln.strip() and not ln.startswith("#")), name)
        entries.append({
            "kind": "reference", "name": name,
            "description": first[:DESCRIPTION_MAX_CHARS],
            "path": f"references/{name}.md",
        })

    return entries
```

```python
"""Databricks App: the AI Cyber Bootcamp 2026 deck viewer and its tutor.

Configuration (values come from the bundle's app resource config.env, see
../../databricks.yml; app.yaml carries only the command):

  DECKS_VOLUME_PATH    volume dir holding one folder per deck, each with an

  TUTOR_SKILLS_PATH    workspace files dir holding the generated tutor-skills tree
  TUTOR_LABS_PATH      workspace files dir holding the worksheet notebooks
  TUTOR_ANSWERS_PATH   workspace files dir holding the answer notebooks
  TUTOR_HOME_LABS_DIR  folder name of a student's own lab copy under /Workspace/Users/<user>/
  TUTOR_DEV_USER       identity fallback with no forwarded header (local runs only)
"""
import html
import mimetypes
import os
import re
from functools import lru_cache
from pathlib import Path

from databricks.sdk import WorkspaceClient
from databricks.sdk.errors import NotFound
from flask import Blueprint, Flask, Response, abort, jsonify

from tutor.fallback import setup_or_fallback

VOLUME_ROOT = os.environ["DECKS_VOLUME_PATH"].rstrip("/")
COURSE_TITLE = os.environ.get("COURSE_TITLE", "AI Cyber Bootcamp 2026")

app = Flask(__name__)
w = WorkspaceClient()

_TITLE_RE = re.compile(r"<title>(.*?)</title>", re.S | re.I)
_MODULE_RE = re.compile(r"^Module\s+(\d+)\s*:\s*(.+)$")


@lru_cache(maxsize=512)
def read_volume_file(path: str) -> bytes:
    resp = w.files.download(path)
    return resp.contents.read()


def _deck_label(folder: str, title: str | None) -> str:
    """Sidebar label for a deck.

    Deck titles are "AI Cyber Bootcamp 2026 — Module N: Name", so the segment
    after the em dash already carries its own module number; the Final Project's
    tail is just "Final Project" and is used as it stands. A deck with no <title>
    falls back to its folder slug.
    """
    if title:
        tail = title.rsplit("—", 1)[-1].strip() if "—" in title else title.strip()
        m = _MODULE_RE.match(tail)
        if m:
            return f"Module {int(m.group(1))} — {m.group(2).strip()}"
        if tail:
            return tail
    slug = re.sub(r"^\d+-", "", folder).replace("-", " ").strip().title()
    num = re.match(r"(\d+)", folder)
    return f"Module {int(num.group(1))} — {slug}" if num else slug


@lru_cache(maxsize=1)
def list_decks():
    decks = []
    for entry in w.files.list_directory_contents(VOLUME_ROOT):
        if not entry.is_directory:
            continue
        name = os.path.basename(entry.path.rstrip("/"))
        try:
            index = read_volume_file(f"{VOLUME_ROOT}/{name}/index.html")
        except NotFound:
            continue
        m = _TITLE_RE.search(index.decode("utf-8", "replace"))
        title = html.unescape(m.group(1)).strip() if m else None
        decks.append({"id": name, "title": _deck_label(name, title)})
    decks.sort(key=lambda d: d["id"])
    return decks


@app.route("/api/decks")
def api_decks():
    return jsonify(list_decks())


@app.route("/decks/<path:subpath>")
def serve_deck_file(subpath: str):
    if ".." in subpath.split("/"):
        abort(404)
    try:
        data = read_volume_file(f"{VOLUME_ROOT}/{subpath}")
    except NotFound:
        abort(404)
    mime = mimetypes.guess_type(subpath)[0] or "application/octet-stream"
    return Response(data, mimetype=mime)


_INDEX_HTML_PATH = Path(__file__).parent / "static" / "index.html"
try:
    INDEX_HTML = _INDEX_HTML_PATH.read_text(encoding="utf-8")
except FileNotFoundError as e:
    raise RuntimeError(
        f"App shell not found at {_INDEX_HTML_PATH}. "
        "Deploy static/index.html alongside app.py before starting the app."

@app.route("/")
```

```python
class WorkspaceTextFiles:
    """Workspace files (`/Workspace/...`) through the workspace API, read-only.

    The bundle syncs the tutor's skills, the worksheets and the answers into
    `${workspace.file_path}`; none of them is on a volume, so `VolumeFiles`
    cannot reach them. Nothing in the app writes to workspace files -- the
    bundle owns that tree -- so `write` and `delete` raise rather than
    pretending to be a general backend.
    """

    def __init__(self, w):
        self.w = w

    def read(self, path: str) -> bytes:
        from databricks.sdk.service.workspace import ExportFormat
        try:
            return self.w.workspace.download(path, format=ExportFormat.AUTO).read()
        except NotFound as e:
            raise MissingFile(path) from e
        except (TypeError, ValueError):
            # Older SDKs take no `format` on download; fall back to export.
            import base64
            try:
                return base64.b64decode(self.w.workspace.export(path, format=ExportFormat.AUTO).content)
            except NotFound as e:
                raise MissingFile(path) from e

    def write(self, path: str, data: bytes) -> None:
        raise NotImplementedError("the app never writes to workspace files; the bundle owns that tree")

    def list(self, path: str) -> list[str]:
        try:
            return sorted(e.path.rsplit("/", 1)[-1] for e in self.w.workspace.list(path))
        except NotFound:
            return []

    def delete(self, path: str) -> None:
        raise NotImplementedError("the app never writes to workspace files; the bundle owns that tree")

    def exists(self, path: str) -> bool:
        try:
            self.w.workspace.get_status(path)
            return True
        except NotFound:
            return False
```

```python
# One tool result never costs the prompt more than this. Four calls at the cap
# is 48K characters, roughly 12K tokens, inside prompt.py's budget.
MAX_MATERIAL_CHARS = 12_000

_SAFE_NAME = re.compile(r"^[A-Za-z0-9][A-Za-z0-9._-]*$")


def _cap(text: str, what: str) -> str:
    if len(text) <= MAX_MATERIAL_CHARS:
        return text
    return text[:MAX_MATERIAL_CHARS] + f"\n\n[{what} truncated at {MAX_MATERIAL_CHARS} characters]"


def _suggest(name: str, candidates) -> str:
    close = difflib.get_close_matches(name, list(candidates), n=3, cutoff=0.5)
    return f" Closest names: {', '.join(close)}." if close else ""


class SkillLibrary:
    """The generated tutor-skills tree, read through a FileBackend.

    Startup reads exactly one file, `index.json`, written by
    databricks/tools/build_tutor_skills.py. Bodies are read on demand and
    cached, so a repeated `load_skill` in one conversation costs nothing.
    """

    def __init__(self, files: FileBackend, root: str, entries: list[dict]):
        self.files = files
        self.root = root.rstrip("/")
        self._entries = entries
        self._by_name = {e["name"]: e for e in entries}
        self.names = frozenset(self._by_name)
        self._read = lru_cache(maxsize=128)(self._read_uncached)

    @classmethod
    def load(cls, files: FileBackend, root: str) -> "SkillLibrary":
        root = root.rstrip("/")
        raw = files.read(f"{root}/index.json")
        entries = json.loads(raw.decode("utf-8"))
        if not entries:
            raise MissingFile(f"{root}/index.json is empty")
        return cls(files, root, entries)

    def index(self) -> list[dict]:
        """Name, kind and description of everything loadable. Goes in the prompt."""
        return [{"kind": e["kind"], "name": e["name"], "description": e["description"]}
                for e in self._entries]

    def _read_uncached(self, path: str) -> str:
        return self.files.read(f"{self.root}/{path}").decode("utf-8", "replace")

    def _entry(self, name: str, kind: str) -> dict:
        if not _SAFE_NAME.match(name or ""):
            raise MissingFile(f"not a valid {kind} name: {name!r}")
        entry = self._by_name.get(name)
        if entry is None or entry["kind"] != kind:
            raise MissingFile(
                f"no {kind} named {name!r}." + _suggest(name, (
                    e["name"] for e in self._entries if e["kind"] == kind)))
        return entry

    def load_skill(self, name: str) -> str:
        """A skill's body, frontmatter stripped."""
        text = self._read(self._entry(name, "skill")["path"])
        if text.startswith("---"):
            text = text.split("---", 2)[-1].lstrip("\n")
        return _cap(text, f"skill {name}")

    def read_reference(self, name: str) -> str:
        return _cap(self._read(self._entry(name, "reference")["path"]), f"reference {name}")


class _NotesParser(HTMLParser):
    """Pull `<aside class="notes">` text out of a reveal deck, page by page.

    A page number comes from the enclosing top-level `<section>`'s `data-page`
    when the deck builder emitted one, and from the section's 1-based ordinal
    when it did not -- these decks are one section per page, so the two agree.
    """

    def __init__(self):
        super().__init__(convert_charrefs=True)
        self.notes: list[tuple[int, str]] = []
        self._depth = 0
        self._page = 0
        self._in_notes = False
        self._buf: list[str] = []

    def handle_starttag(self, tag, attrs):
        attrs = dict(attrs)
        if tag == "section":
            self._depth += 1
            if self._depth == 1:
                page = attrs.get("data-page", "")
                self._page = int(page) if page.isdigit() else self._page + 1
        elif tag == "aside" and "notes" in (attrs.get("class") or "").split():
            self._in_notes = True
            self._buf = []

    def handle_startendtag(self, tag, attrs):
        if self._in_notes and tag == "br":
            self._buf.append(" ")

    def handle_endtag(self, tag):
        if tag == "aside" and self._in_notes:
            self._in_notes = False
            text = " ".join("".join(self._buf).split())
            if text:
                self.notes.append((self._page, text))
        elif tag == "section":
            self._depth = max(0, self._depth - 1)

    def handle_data(self, data):
        if self._in_notes:
            self._buf.append(data)


class CourseMaterial:
    """The bootcamp's own text: worksheet notebooks, answer notebooks, deck notes."""

    def __init__(self, files: FileBackend, labs_path: str, answers_path: str,
                 decks_path: str, deck_files: FileBackend):
        self.files = files
        self.labs_path = labs_path.rstrip("/")
        self.answers_path = answers_path.rstrip("/")
        self.decks_path = decks_path.rstrip("/")
        self.deck_files = deck_files
        self._notes = lru_cache(maxsize=32)(self._read_deck_notes_uncached)

    # --- decks -----------------------------------------------------------

    def _read_deck_notes_uncached(self, deck: str) -> tuple[tuple[int, str], ...]:
        if not _SAFE_NAME.match(deck or ""):
            raise MissingFile(f"not a valid deck id: {deck!r}")
        raw = self.deck_files.read(f"{self.decks_path}/{deck}/index.html")
        parser = _NotesParser()
        parser.feed(raw.decode("utf-8", "replace"))
        parser.close()
        return tuple(parser.notes)

    def read_deck_notes(self, deck: str) -> list[tuple[int, str]]:
        return list(self._notes(deck))

    def note_for_slide(self, deck: str, slide: int) -> str | None:
        for page, text in self._notes(deck):
            if page == slide:
                return text
        return None

    def render_deck_notes(self, deck: str) -> str:
        lines = [f"Slide {page}: {text}" for page, text in self._notes(deck)]
        return _cap("\n\n".join(lines) if lines else "This deck has no speaker notes.",
                    f"notes for {deck}")

    # --- labs ------------------------------------------------------------

    def _list(self, path: str) -> list[str]:
        return self.files.list(path)

    def _read_notebook_json(self, path: str) -> dict:
        return json.loads(self.files.read(path).decode("utf-8", "replace"))

    def _resolve(self, worksheet: str, root: str) -> str:
        """Match "4.2", a full filename, or any case variant of either."""
        if "/" in worksheet or ".." in worksheet:
            raise MissingFile(f"not a valid worksheet: {worksheet!r}")
        names = [n for n in self._list(root) if n.endswith(".ipynb")]
        wanted = worksheet.strip().lower()
        for name in names:
            if name.lower() == wanted:
                return f"{root}/{name}"
        number = wanted[:-6] if wanted.endswith(".ipynb") else wanted
        number = re.sub(r"^worksheet[_ ]", "", number)
        number = number.split("_", 1)[0]
        for name in names:
            if name.lower().startswith(f"worksheet_{number}_"):
                return f"{root}/{name}"
        available = sorted({re.sub(r"^Worksheet_([\d.]+)_.*", r"\1", n) for n in names})
        raise MissingFile(
            f"no worksheet {worksheet!r} under {root}. Available: {', '.join(available)}")

    def read_lab(self, worksheet: str, answers: bool = False) -> str:
        """A notebook as text: markdown and code cells, in order, outputs dropped.

        Answers are not secret in this course (spec decision 3), so
        `answers=True` reads the matching notebook from the answers tree.
        """
        root = self.answers_path if answers else self.labs_path
        path = self._resolve(worksheet, root)
        nb = self._read_notebook_json(path)
        parts = [f"# {path.rsplit('/', 1)[-1]}"]
        for cell in nb.get("cells", []):
            kind = cell.get("cell_type")
            if kind not in ("markdown", "code"):
                continue
            source = cell.get("source")
            body = "".join(source) if isinstance(source, list) else (source or "")
            if body.strip():
                parts.append(f"[{kind}]\n{body.rstrip()}")
        return _cap("\n\n".join(parts), f"notebook {path.rsplit('/', 1)[-1]}")
```

### Task 7: `tutor/llm.py` — the client and the tool loop

**Files:**
- Create: `databricks/deck-viewer/tutor/llm.py`, `databricks/deck-viewer/tests/test_llm.py`

**Interfaces:**
- Consumes: `SkillLibrary` and `CourseMaterial` from Task 6.
- Produces:
  - `TOOL_SCHEMAS: list[dict]` — the four OpenAI function definitions.
  - `Toolbox(library, material)` with `.call(name, arguments: dict) -> str` and `.schemas() -> list[dict]`.
  - `Answer` — a frozen dataclass `(text: str, sources: list[dict], usage: dict, tool_calls: list[str])`.
  - `Tutor(client, model, toolbox, *, max_tool_calls=4, max_output_tokens=900, reasoning_effort="low")`, `Tutor.from_workspace(w, endpoint, toolbox) -> Tutor`, `.answer(messages) -> Answer`.

**The client gotcha, carried over verbatim from the reference.** Do not call `w.serving_endpoints.get_open_ai_client()`. It is deprecated in `databricks-sdk` 0.133 and hard-imports the real `httpx` package to build its Bearer-auth transport, while `openai` 3.x depends on `httpx`'s successor package `httpx2` and does not install `httpx` at all — so the call raises `ModuleNotFoundError: No module named 'httpx'` on a clean `pip install` of this app's own requirements, in production, not just in one tooling venv. Build the client by hand instead: `OpenAI(base_url=f"{w.config.host}/serving-endpoints", api_key=token)` where `token` is a **zero-argument callable** returning `w.config.authenticate()["Authorization"].split(" ", 1)[1]`. `openai.OpenAI` accepts `api_key` as `str | Callable[[], str] | None`, so every request pulls a fresh token through the workspace client's own refresh — which is what the SDK helper was doing internally — with no `httpx` dependency at all.

**Reasoning effort, verified against the docs 2026-09-02.** The parameter is `reasoning_effort`, **top level in the request body, not nested**, on the same OpenAI-compatible chat-completions surface — https://docs.databricks.com/aws/en/machine-learning/model-serving/query-reason-models. That page names this endpoint explicitly: "`databricks-glm-5-2`, `databricks-deepseek-v4-pro-0813`, `databricks-deepseek-v4-flash-0731`, and `databricks-kimi-k3`. Hybrid reasoning. These models reason by default and support both deeper reasoning and fast, instant replies when `reasoning_effort` is set to `"none"`. … For DeepSeek V4 Pro (0813) and DeepSeek V4 Flash (0731), this parameter accepts values of `"low"`, `"high"`, or `"max"`. Other effort values fall back to `"max"`." Two consequences the code must respect: **omitting it means `"max"`**, which is the expensive default, so it is always sent; and `"low"` is a valid value for this model while `"medium"` is not. Because `reasoning_effort` is not in the `openai` Python client's typed parameter list for every version, it is passed through `extra_body={"reasoning_effort": …}`, which puts it at the top level of the JSON body — exactly where the doc's curl example has it.

**Not streaming.** The reference streamed because it had one model call per question. A tool loop has up to five, and only the last produces prose; streaming the intermediate turns shows the student nothing. The loop runs non-streaming, and `/chat` emits the finished answer as a single SSE `token` frame, which the front end's accumulate-then-render path already handles. Non-streaming also hands back `response.usage` for free, which Task 12's cost line needs. If streaming is wanted later, stream only the final turn.

```python
CLIENT. `Tutor.from_workspace` builds a plain `openai.OpenAI` by hand -- it does
NOT use `w.serving_endpoints.get_open_ai_client()`. That method is deprecated in
`databricks-sdk` 0.133 and hard-imports the real `httpx` package to build its
Bearer-auth transport; `openai` 3.x depends on `httpx`'s successor package
`httpx2` and does not install `httpx` at all, so the bare call raises
`ModuleNotFoundError: No module named 'httpx'` -- exactly what a fresh pip
install of this app's requirements hits in production, not a quirk of one venv.
The fix is to drop the helper: `OpenAI(base_url=f"{w.config.host}/serving-endpoints",
api_key=token)` where `token` is a zero-arg callable reading
`w.config.authenticate()`'s Authorization header. `openai.OpenAI` accepts
`api_key` as `str | Callable[[], str] | None`, so every request pulls a fresh
token through the workspace client's own refresh -- what the helper did
internally -- with no `httpx` at all. Authenticated as whichever principal `w`
is: the app's own service principal at runtime, a CLI profile locally.

and it is sent on every call. Per
https://docs.databricks.com/aws/en/machine-learning/model-serving/query-reason-models
this endpoint is hybrid-reasoning and "defaults to `max` when reasoning_effort is
omitted"; DeepSeek V4 Flash (0731) accepts `low`, `high` and `max`, and anything

setting, so spec decision 5's `low` is always explicit. It goes through
`extra_body` because the openai client's typed signature does not carry it on
every version; extra_body lands it at the top level of the JSON body.

NO STREAMING. A tool loop makes up to five model calls and only the last writes
prose, so streaming the intermediate turns shows a student nothing. The loop runs
non-streaming and the route emits the finished text as one SSE frame, which the
front end's accumulate-then-render path already handles. It also hands back
`response.usage`, which the deployment notes' cost line needs.

class Toolbox:
    """Dispatch from a tool name to the library or the course material.

    A tool never raises into the loop: a bad name or a missing file comes back as
    a sentence the model can read and recover from, because a raised exception
    would lose the whole answer over a typo the model could have fixed itself.
    """

    def __init__(self, library, material):
        self.library = library
        self.material = material
        self.sources: list[dict] = []

    def schemas(self) -> list[dict]:
        return TOOL_SCHEMAS

    def call(self, name: str, arguments: dict) -> str:
        try:
            if name == "load_skill":
                key = arguments["name"]
                out = self.library.load_skill(key)
                self._record("skill", key)
            elif name == "read_reference":
                key = arguments["name"]
                out = self.library.read_reference(key)
                self._record("reference", key)
            elif name == "read_lab":
                key = arguments["worksheet"]
                out = self.material.read_lab(key, answers=bool(arguments.get("answers")))
                self._record("answer" if arguments.get("answers") else "lab", key)
            elif name == "read_deck_notes":
                key = arguments["deck"]
                out = self.material.render_deck_notes(key)
                self._record("deck", key)
            else:
                return f"Unknown tool {name!r}. Use one of: " + ", ".join(
                    t["function"]["name"] for t in TOOL_SCHEMAS)
        except KeyError as e:
            return f"Missing required argument {e.args[0]!r} for {name}."
        except MissingFile as e:
            return str(e)
        except Exception:
            logger.exception("tool %s failed with %r", name, arguments)
            return f"{name} failed. Answer from what you already have."
        return out

    def _record(self, kind: str, name: str) -> None:
        entry = {"kind": kind, "name": name}
        if entry not in self.sources:
            self.sources.append(entry)


@dataclass(frozen=True)
class Answer:
    text: str
    sources: list[dict] = field(default_factory=list)
    usage: dict = field(default_factory=dict)
    tool_calls: list[str] = field(default_factory=list)


class Tutor:
    def __init__(self, client, model: str, toolbox: Toolbox, *,
                 max_tool_calls: int = MAX_TOOL_CALLS,
                 max_output_tokens: int = MAX_OUTPUT_TOKENS,
                 reasoning_effort: str = REASONING_EFFORT):
        self.client = client
        self.model = model
        self.toolbox = toolbox
        self.max_tool_calls = max_tool_calls
        self.max_output_tokens = max_output_tokens
        self.reasoning_effort = reasoning_effort

    @classmethod
    def from_workspace(cls, w, endpoint: str, toolbox: Toolbox, **kw) -> "Tutor":
        def token() -> str:
            return w.config.authenticate()["Authorization"].split(" ", 1)[1]

        client = OpenAI(base_url=f"{w.config.host}/serving-endpoints", api_key=token)
        return cls(client, endpoint, toolbox, **kw)

    def _complete(self, messages: list[dict], *, with_tools: bool):
        kwargs = {
            "model": self.model,
            "messages": messages,
            "max_tokens": self.max_output_tokens,
            "temperature": TEMPERATURE,
            "extra_body": {"reasoning_effort": self.reasoning_effort},
        }
        if with_tools:
            kwargs["tools"] = self.toolbox.schemas()
            kwargs["tool_choice"] = "auto"
        return self.client.chat.completions.create(**kwargs)

    def answer(self, messages: list[dict]) -> Answer:
        convo = list(messages)
        used: list[str] = []
        prompt_tokens = completion_tokens = turns = 0

        while True:
            budget_left = self.max_tool_calls - len(used)
            response = self._complete(convo, with_tools=budget_left > 0)
            turns += 1
            usage = getattr(response, "usage", None)
            if usage is not None:
                prompt_tokens += getattr(usage, "prompt_tokens", 0) or 0
                completion_tokens += getattr(usage, "completion_tokens", 0) or 0

            message = response.choices[0].message
            calls = list(getattr(message, "tool_calls", None) or [])
            if not calls:
                text = (message.content or "").strip() or EMPTY_ANSWER
                return Answer(
                    text=text, sources=list(self.toolbox.sources),
                    usage={"prompt_tokens": prompt_tokens,
                           "completion_tokens": completion_tokens, "turns": turns},
                    tool_calls=used,
                )

            # The assistant turn must be echoed back with its tool_calls before
            # the tool results, or the endpoint rejects the orphaned tool role.
            convo.append({
                "role": "assistant",
                "content": message.content or "",
                "tool_calls": [{"id": c.id, "type": "function",
                                "function": {"name": c.function.name,
                                             "arguments": c.function.arguments}} for c in calls],
            })

            for call in calls[:budget_left]:
                name = call.function.name
                try:
                    arguments = json.loads(call.function.arguments or "{}")
                except ValueError:
                    arguments = {}
                result = self.toolbox.call(name, arguments)
                label = next(iter(arguments.values()), "") if arguments else ""
                used.append(f"{name}:{label}" if label else name)
                convo.append({"role": "tool", "tool_call_id": call.id,
                              "name": name, "content": result})

            for call in calls[budget_left:]:
                convo.append({"role": "tool", "tool_call_id": call.id, "name": call.function.name,
                              "content": "Tool budget spent. Answer from what you have."})
```

**The budget, with its numbers.** Every one is a cap this module enforces, not a guess about what the model will do.

| Part | Cap | Why this number |
|---|---|---|
| Whole prompt | `BUDGET_TOKENS = 32_000` | The endpoint has 1M context, so this is a cost ceiling, not a technical one. At $0.14/M input it puts a full-budget question at $0.0045 in, plus $0.00025 out for 900 tokens at $0.28/M — the top of the spec's $0.001–$0.006 band. Cached prefix at $0.03/M puts a repeat question near $0.001, which is the bottom of it. |
| Skill index | `SKILL_INDEX_MAX_TOKENS = 6_000` | The real index is 60 entries and about 4,100 tokens, so the cap is headroom rather than a trim. It is enforced anyway: a future subskill must not silently push the deck notes out. |
| Deck notes | `DECK_NOTES_MAX_TOKENS = 6_000` | About 40 slides of notes. A longer deck is truncated at a slide boundary with a marker rather than mid-sentence. |
| History reserve | `HISTORY_RESERVE_TOKENS = 2_000` | Roughly eight short turns. Reserved before the material is fitted, so a long deck can never crowd out the conversation. |
| Tool results | `MAX_MATERIAL_CHARS = 12_000` each, four calls | Set in Task 6. 48K characters, about 12K tokens, which is why the four fixed parts above stop at 14K. |
| Output | `MAX_OUTPUT_TOKENS = 900` | Set in Task 7. Long enough for an explanation with a code block, short enough that no answer is a wall. |

`estimate_tokens` is the reference's `len(text) // 4`. It is an estimate, and it is deliberately cheap: the budget is a cost guardrail with an order of magnitude of headroom against the model's real context, so a tokenizer dependency would buy precision nothing needs.

**What the tutor will and will not do.** Spec decision 3 says the answers ship alongside the worksheets and are not secret. So the stance is not "never show an answer" — it is "explain first, and show the answer when asked, because hiding it from a student who can open the file is theatre." The prompt says exactly that, and `read_lab(..., answers=True)` exists so the model can act on it.

```python
"""The tutor's stance, and budgeted assembly of the messages it is sent.

Order in the user message, deliberately: the deck and slide the student has
open, then that slide's own note, then the rest of the deck's notes, then the
question. The pinned note leads because "what does this slide mean" is the
commonest question a student asks with a deck open, and the model should not
have to hunt for the one note that answers it.

The skill index rides in the system message rather than the user message so the
whole system block is byte-identical across a conversation, which is what makes
it cacheable at $0.03/M instead of $0.14/M.
"""
from __future__ import annotations

# Cost ceiling, not a context limit -- the endpoint has 1M. At $0.14/M input a
# full-budget question costs about $0.0045 in and $0.00025 out, the top of the
# spec's $0.001-$0.006 band; a cached prefix puts a repeat near the bottom.
BUDGET_TOKENS = 32_000

# The real index is about 4,100 tokens across 60 entries. The cap is headroom,
# enforced so a future subskill cannot silently push the deck notes out.
SKILL_INDEX_MAX_TOKENS = 6_000

# About 40 slides of notes. A longer deck is cut at a slide boundary.
DECK_NOTES_MAX_TOKENS = 6_000

# Roughly eight short turns, reserved before the material is fitted so a long
# deck can never crowd out the conversation.
HISTORY_RESERVE_TOKENS = 2_000

SYSTEM_STANCE = """You are the tutor for AI Cyber Bootcamp 2026, a five-day course that goes from pandas and exploratory analysis through classical machine learning to LLM agents, with every lab set on a security problem.

What you do:
- Explain. Take the student's question, name the idea underneath it, and answer from the course's own material and from your skill library.
- Ground the answer. The deck the student has open, its speaker notes and the labs are the course's language; use them, and say which slide or worksheet you are drawing on.
- Say when something is outside the course. Name the nearest thing the course does cover rather than inventing a lesson it does not teach.

What you do not do:
- You do not hand over a finished solution as the first move on a lab exercise. Explain the idea, point at the cell, give the next step. If the student pastes their own attempt, say what is wrong with it.
- The answer notebooks are NOT secret in this course; they ship alongside the worksheets and every student can open them. So if a student asks you outright for the answer, show it and explain why it works. Refusing something they can read for themselves wastes their time.
- You do not invent data, file names, results or numbers that are not in the material you were given or that you loaded.

Your tools, and when to reach for them:
- load_skill(name) — the system message lists every skill and what it covers. Load one when its description matches the question.
- read_reference(name) — a reference document from the same library.
- read_lab(worksheet, answers) — a worksheet notebook as text, or its answer notebook with answers=true.
- read_deck_notes(deck) — the speaker notes of a deck other than the open one; the open deck's notes are already below.
Call at most a few tools, then answer. Do not narrate the tool calls.

How you write:
- Plain sentences. No greeting, no praise for the question, no closing offer.
- Short paragraphs. Lists only for genuinely parallel items. Code only when the question is about code.
- Markdown is fine: bold, lists, fenced code."""


def estimate_tokens(text: str) -> int:
    """Four characters to a token. An estimate; the budget has an order of
    magnitude of headroom against the endpoint's real context, so a tokenizer
    dependency would buy precision nothing here needs."""
    return max(1, len(text or "") // 4)


def render_index(entries) -> str:
    """The skill index as one line per entry, capped."""
    lines, running = [], 0
    for entry in entries:
        kind = "" if entry["kind"] == "skill" else " (reference)"
        line = f"- {entry['name']}{kind}: {entry['description']}"
        cost = estimate_tokens(line)
        if running + cost > SKILL_INDEX_MAX_TOKENS:
            lines.append(f"- [{len(entries) - len(lines)} more entries not listed]")
            break
        lines.append(line)
        running += cost
    return "\n".join(lines)


def build_system(index_text: str) -> str:
    return (
        f"{SYSTEM_STANCE}\n\n"
        "Your skill library. Each line is a name you can pass to load_skill, or to "
        "read_reference where it says reference, and what it covers:\n\n"
        f"{index_text}"
    )


# Exported for tests and for anything that wants the stance without an index.
SYSTEM = build_system("- ds-evaluate: (index rendered per request)")


def _truncate_notes(notes: str) -> str:
    """Cut deck notes at a slide boundary, never mid-sentence."""
    if estimate_tokens(notes) <= DECK_NOTES_MAX_TOKENS:
        return notes
    kept, running = [], 0
    for block in notes.split("\n\n"):
        cost = estimate_tokens(block)
        if running + cost > DECK_NOTES_MAX_TOKENS:
            break
        kept.append(block)
        running += cost
    return "\n\n".join(kept) + "\n\n[deck notes truncated to fit the prompt budget]"


def _render_user_block(question: str, deck, slide, deck_notes, pinned_note) -> str:
    lines = []
    if deck:
        where = f"The student has deck {deck} open"
        if slide:
            where += f", at slide {slide}"
        lines += [where + ".", ""]
    if pinned_note:
        lines += ["Speaker note for the slide currently open:", "", pinned_note, ""]
    if deck_notes:
        lines += ["Speaker notes for the whole open deck:", "", _truncate_notes(deck_notes), ""]
    lines.append(f"Question: {question}")
    return "\n".join(lines)


def build_messages(question: str, *, index_entries, deck, slide, deck_notes,
                   pinned_note, history, budget_tokens: int = BUDGET_TOKENS) -> list[dict]:
    system = build_system(render_index(index_entries))
    user = _render_user_block(question, deck, slide, deck_notes, pinned_note)

    running = estimate_tokens(system) + estimate_tokens(user)
    # History is fitted last and oldest-first-dropped: the recent turns are the
    # ones the student is actually following up on.
    ceiling = budget_tokens - HISTORY_RESERVE_TOKENS if running < budget_tokens else budget_tokens
    kept = []
    for turn in reversed(history or []):
        entry = {"role": turn["role"], "content": turn["content"]}
        cost = estimate_tokens(entry["content"])
        if running + cost > max(ceiling, running):
            break
        kept.append(entry)
        running += cost
    kept.reverse()

    return [{"role": "system", "content": system}, *kept, {"role": "user", "content": user}]
```

```python
"""The tutor's HTTP surface: per-user conversations and one answered question.

Two routes the reference had are gone with the retrieval index: /scopes (there
are no scopes) and /slide (there is no chunk to look a slide up in). Everything
else -- identity, conversation CRUD, lab links, and the throttle's permit
discipline -- is the reference's, unchanged in behaviour.
"""
import json
import logging
import urllib.parse

from flask import Blueprint, Response, jsonify, request

from tutor.files import MissingFile
from tutor.identity import current_user
from tutor.prompt import build_messages
from tutor.sessions import CONV_ID_RE
from tutor.throttle import Busy, TooManyRequests

logger = logging.getLogger(__name__)

TOO_MANY_REQUESTS_MESSAGE = "You've asked a lot of questions in the last few minutes. Wait a bit and try again."
BUSY_MESSAGE = "The tutor is answering other questions right now. Try again in a moment."
UNKNOWN_CONVERSATION_MESSAGE = "That conversation was not found."
INVALID_NOTEBOOK_MESSAGE = "That notebook path is not valid."
EMPTY_QUESTION_MESSAGE = "Ask a question first."
ANSWER_ERROR_MESSAGE = "Something went wrong answering that. Ask again."
SETUP_ERROR_MESSAGE = "Something went wrong getting ready to answer that. Try again."
HISTORY_TURNS = 8


def _sse(event: str, data) -> str:
    return f"event: {event}\ndata: {json.dumps(data)}\n\n"


def make_blueprint(library, material, tutor, store, throttle, *, dev_user: str | None,
                   workspace_host: str, labs_shared: str, home_labs_dir: str,
                   lab_exists) -> Blueprint:
    bp = Blueprint("tutor", __name__)

    def _user() -> str:
        return current_user(request.headers, dev_user)

    @bp.route("/me", methods=["GET"])
    def me():
        return jsonify({"user": _user()})

    @bp.route("/conversations", methods=["GET"])
    def list_conversations():
        return jsonify(store.list(_user()))

    @bp.route("/conversations", methods=["POST"])
    def create_conversation():
        body = request.get_json(force=True, silent=True) or {}
        return jsonify(store.create(_user(), body.get("scope"))), 201

    @bp.route("/conversations/<conv_id>", methods=["GET"])
    def get_conversation(conv_id):
        conv = store.get(_user(), conv_id)
        if conv is None:
            return jsonify({"message": UNKNOWN_CONVERSATION_MESSAGE}), 404
        return jsonify(conv)

    @bp.route("/conversations/<conv_id>", methods=["DELETE"])
    def delete_conversation(conv_id):
        store.delete(_user(), conv_id)
        return "", 204

    @bp.route("/lab-link", methods=["GET"])
    def lab_link():
        notebook = request.args.get("notebook", "")
        if ".." in notebook.split("/"):
            return jsonify({"message": INVALID_NOTEBOOK_MESSAGE}), 400
        own = f"/Workspace/Users/{_user()}/{home_labs_dir}/{notebook}"
        path = own if lab_exists(own) else f"{labs_shared}/{notebook}"
        return jsonify({"url": f"{workspace_host}/#workspace{urllib.parse.quote(path, safe='/')}"})

    @bp.route("/chat", methods=["POST"])
    def chat():
        user = _user()
        body = request.get_json(force=True, silent=True) or {}
        conversation_id = body.get("conversation_id")
        deck = body.get("deck")
        slide = body.get("slide")
        question = (body.get("message") or "").strip()

        if not question:
            return jsonify({"message": EMPTY_QUESTION_MESSAGE}), 400

        throttle_cm = throttle.acquire(user)
        try:
            throttle_cm.__enter__()
        except TooManyRequests:
            return jsonify({"message": TOO_MANY_REQUESTS_MESSAGE}), 429
        except Busy:
            return jsonify({"message": BUSY_MESSAGE}), 503

        released = False

        def release():
            nonlocal released
            if not released:
                released = True
                throttle_cm.__exit__(None, None, None)

        # Everything from here to the stream's start can raise and must still
        # release the permit it took above: a leaked permit locks every later
        # request in this process out with Busy.
        try:
            if conversation_id:
                # conversation_id arrives in a JSON body, where "/" is legal --
                # unlike the URL-path routes above, where Flask's converter will
                # not match one. SessionStore validates the same shape
                # independently; this is the belt on top of that suspender.
                if not isinstance(conversation_id, str) or not CONV_ID_RE.match(conversation_id):
                    release()
                    return jsonify({"message": UNKNOWN_CONVERSATION_MESSAGE}), 404
                conv = store.get(user, conversation_id)
                if conv is None:
                    release()
                    return jsonify({"message": UNKNOWN_CONVERSATION_MESSAGE}), 404
            else:
                conv = store.create(user, deck)

            deck_notes = pinned_note = None
            if deck:
                try:
                    deck_notes = material.render_deck_notes(deck)
                    if slide is not None:
                        pinned_note = material.note_for_slide(deck, int(slide))
                except (MissingFile, TypeError, ValueError):
                    # A deck the volume does not have, or a nonsense slide
                    # number, costs the question its grounding -- not the answer.
                    logger.warning("no notes for deck=%r slide=%r", deck, slide)

            messages = build_messages(
                question, index_entries=library.index(), deck=deck, slide=slide,
                deck_notes=deck_notes, pinned_note=pinned_note,
                history=conv["messages"][-HISTORY_TURNS:],
            )
        except Exception:
            release()
            logger.exception("tutor chat setup failed (user=%s)", user)
            return jsonify({"message": SETUP_ERROR_MESSAGE}), 500

        def gen():
            try:
                yield _sse("meta", {"conversation_id": conv["id"]})
                answer = tutor.answer(messages)
                logger.info("tutor answered user=%s deck=%s tools=%s usage=%s",
                            user, deck, answer.tool_calls, answer.usage)
                yield _sse("token", {"text": answer.text})
                yield _sse("sources", answer.sources)
                store.append(user, conv["id"], question, answer.text, answer.sources)
                yield _sse("done", {})
            except Exception:
                logger.exception("tutor answer failed (user=%s conversation=%s)", user, conv["id"])
                yield _sse("error", {"message": ANSWER_ERROR_MESSAGE})
            finally:
                release()

        resp = Response(gen(), mimetype="text/event-stream",
                        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"})
        # Belt on top of the generator's own finally: a generator handed to the
        # WSGI server and never advanced even once (the client disconnects before
        # the first read) has no suspended frame, so its close() runs no code.
        # call_on_close always fires; release's own flag makes a second call a
        # no-op.
        resp.call_on_close(release)
        return resp

    return bp
```

```python
    DATABRICKS_CONFIG_PROFILE=gtk-workspace .venv/bin/python local_run.py \
        --volume /path/to/fake/volume --workspace /path/to/fake/workspace

The model calls are real -- they go to the workspace serving endpoint through
the CLI profile's credentials -- so this exercises the tool loop, the prompt and
the routes end to end. Only the Databricks Apps runtime and its forwarded
identity headers are simulated, by TUTOR_DEV_USER.

Not deployed: the bundle's app source is app.py, and this file is a developer
entry point that lives beside it.

import argparse
import os
import sys
from pathlib import Path

from databricks.sdk import WorkspaceClient
from flask import Flask

sys.path.insert(0, str(Path(__file__).resolve().parent))

from tutor.files import LocalFiles  # noqa: E402
from tutor.llm import Toolbox, Tutor  # noqa: E402
from tutor.routes import make_blueprint  # noqa: E402
from tutor.sessions import SessionStore  # noqa: E402
from tutor.skills import CourseMaterial, SkillLibrary  # noqa: E402
from tutor.throttle import Throttle  # noqa: E402


def build(volume: Path, workspace: Path, endpoint: str, dev_user: str) -> Flask:
    w = WorkspaceClient()
    vol = LocalFiles(volume)
    ws = LocalFiles(workspace)
    library = SkillLibrary.load(ws, "/tutor-skills")
    material = CourseMaterial(files=ws, labs_path="/notebooks", answers_path="/answers",
                              decks_path="/decks", deck_files=vol)
    tutor = Tutor.from_workspace(w, endpoint, Toolbox(library, material))

    os.environ.setdefault("DECKS_VOLUME_PATH", str(volume / "decks"))
    app = Flask(__name__, static_folder="static", static_url_path="/static")

    @app.route("/")
    def index():
        html = (Path(__file__).parent / "static" / "index.html").read_text(encoding="utf-8")
        return html.replace("__COURSE_TITLE__", "AI Cyber Bootcamp 2026")

    @app.route("/api/decks")
    def decks():
        from flask import jsonify
        names = sorted(p.name for p in (volume / "decks").iterdir() if p.is_dir())
        return jsonify([{"id": n, "title": n} for n in names])

    @app.route("/decks/<path:subpath>")
    def deck_file(subpath):
        from flask import Response, abort
        import mimetypes
        if ".." in subpath.split("/"):
            abort(404)
        p = volume / "decks" / subpath
        if not p.is_file():
            abort(404)
        return Response(p.read_bytes(),
                        mimetype=mimetypes.guess_type(subpath)[0] or "application/octet-stream")

    app.register_blueprint(
        make_blueprint(library, material, tutor, SessionStore(vol, "/tutor_state"), Throttle(),
                       dev_user=dev_user, workspace_host=w.config.host,
                       labs_shared="/Workspace/Users/local/notebooks",
                       home_labs_dir="AI Cyber Bootcamp 2026", lab_exists=lambda p: False),
        url_prefix="/api/tutor")
    return app


if __name__ == "__main__":
```

```python
            if line.startswith("event:"):
                event = line[6:].strip()
            elif line.startswith("data:"):
                payload = json.loads(line[5:].strip())
                if event == "token":
                    text.append(payload["text"])
                elif event == "sources":
                    sources = payload
                elif event == "error":
                    error = payload.get("message")
    return {"text": "".join(text), "sources": sources, "error": error}


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--app", default="bootcamp-slides")
    args = ap.parse_args(argv)

    w = WorkspaceClient()
    app = w.apps.get(args.app)
    url = app.url.rstrip("/")
    headers = dict(w.config.authenticate())  # Authorization; never printed
    print(f"app: {args.app} at {url}")

    decks = json.loads(urllib.request.urlopen(
        urllib.request.Request(f"{url}/api/decks", headers=headers), timeout=60).read())
    by_number = {}
    for d in decks:
        try:
            by_number[int(d["id"][:2])] = d["id"]
        except ValueError:
            pass
    print(f"decks listed: {len(decks)}")

    failures = 0
    for number, question in QUESTIONS:
        deck = by_number.get(number)
        try:
            result = ask(url, headers, deck, question)
        except Exception as e:
            print(f"module {number:>2}  REQUEST FAILED  {type(e).__name__}: {e}")
            failures += 1
            continue
        if result["error"]:
            print(f"module {number:>2}  ERROR  {result['error']}")
            failures += 1
            continue
        loaded = ", ".join(f"{s['kind']}:{s['name']}" for s in result["sources"]) or "(nothing)"
        print(f"module {number:>2}  deck={deck or '-'}  loaded={loaded}")
        print(f"           {result['text'][:180].replace(chr(10), ' ')}…")
        if not result["sources"]:
            failures += 1

    print(f"\n{len(QUESTIONS) - failures}/{len(QUESTIONS)} modules loaded something")
    return 1 if failures else 0


if __name__ == "__main__":
    sys.exit(main())
```
