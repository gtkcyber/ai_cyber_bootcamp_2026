# course-module-13

Module 13 of AI Cyber Bootcamp 2026: AI Agents.

## What this module teaches

Agents as state graphs in LangGraph, built up over five worksheets: a single-node email classifier, an agent that calls tools in a loop, conditional routing on the state, an interrupt that puts a human in the loop before an action commits, and a supervisor delegating to several specialist agents. Where each pattern earns its complexity, and where a plain function call would have done.
