# course-module-03

Module 3 of AI Cyber Bootcamp 2026: Feature Engineering.

## What this module teaches

Turning raw domain names into features a classifier can use: length, Shannon entropy, vowel and digit ratios, n-gram frequency against an English corpus, and dictionary-word membership. Why a feature has to be computable at scoring time, and why a feature that encodes the label leaks. The frame this worksheet writes is the input to Module 4.
