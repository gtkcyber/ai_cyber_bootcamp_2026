# course-module-07

Module 7 of AI Cyber Bootcamp 2026: Attacking Machine Learning Models.

## What this module teaches

Attacking the models the earlier modules built. 7.1 evades the saved DGA decision tree by moving a domain across the boundary in feature space. 7.2 runs a fast gradient sign method attack on an image classifier, showing how a perturbation invisible to a person flips the prediction. The lesson is the threat model: a deployed model is an attack surface.
